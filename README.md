## 👨‍💻 About Me

> **Curious about how intelligent software works, how large systems stay reliable, and how good engineering turns complex ideas into useful products.**

Hello! I'm **Saikat**, a software engineer focused on **Python engineering, Generative AI, data systems, Linux, cloud infrastructure, and developer automation**. I enjoy connecting software fundamentals with emerging AI capabilities: not simply calling an LLM API, but understanding the data pipelines, retrieval mechanisms, system architecture, evaluation strategies, deployment patterns, and operational trade-offs that make an application dependable.

My interests span the full engineering journey, from writing clean, testable Python code to investigating Linux systems, designing APIs, working with SQL and distributed data processing, and exploring how AI-powered workflows can be monitored and improved. I approach engineering as an ongoing process of **learning the fundamentals, building practical implementations, measuring results, and refining the design**.

**What I'm focusing on:**

- 🧠 **Generative AI & LLM applications:** prompting, embeddings, retrieval-augmented generation (RAG), tool calling, AI agents, context management, and evaluation.
- 🐍 **Python & backend engineering:** API development, concurrency, robust error handling, testing, maintainability, and performance.
- 🗃️ **Data engineering:** SQL, data modelling, ETL/ELT, validation, PySpark, and scalable data workflows.
- 🐧 **Linux & infrastructure:** shell scripting, troubleshooting, process and resource analysis, monitoring, scheduling, and automation.
- ☁️ **Cloud & delivery:** AWS concepts, containers, CI/CD, observability, and reliable application deployment.
- 📚 **Computer science foundations:** algorithms, data structures, system design, and the mathematics behind machine learning.

I use this GitHub profile as a **living engineering notebook and portfolio**: a place for experiments, interview preparation, practical tools, documented examples, and projects that gradually move from prototypes toward production-minded implementations.
